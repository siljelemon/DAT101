1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants (const) should be used when a value does not need to change. Variables (let) should be used when a value needs to change or be reassigned. They can't all be constants because some values need to change during the execution of a program.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses change the order of operations in an expression. JavaScript calculates what is inside the parentheses first, which can change the final result.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. By using the toFixed() to limit a floating-point number to a given number of decimal places. The number inside the parentheses of toFixed() determines how many decimal places the number will be rounded to.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We can round the floating-point values to the same number of decimal places before comparing them. For example, 12.19999 and 12.2 are both 12.2 when rounded to one decimal place.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return a boolean value, either true or false. We can use comparison operators such as ===, !==, >, < and >= to check if a statement is true or false.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() generates a random decimal number between 0 and 1. We can use it to create random values, for example a random number within a specific range.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. The modulus operator (%) returns the remainder after a division. We can use it when we need to find what is left over after dividing a number into equal parts.
